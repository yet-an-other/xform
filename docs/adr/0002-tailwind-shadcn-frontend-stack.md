# Tailwind CSS v4 + shadcn/ui (Base UI primitives) for dashboard styling and components

The dashboard will grow richer (users table, drill-down dialogs, QR codes), so styling and accessible component primitives are adopted up front rather than retrofitted. Tailwind v4 is the single styling system — the palette lives in `@theme` tokens in CSS, no config file, no parallel hand-written stylesheet. shadcn/ui supplies complex components (dialog, dropdown, tooltip, table, switch) by copying their source into the repo: we own and read that code, matching the project's minimal-dependency philosophy (pure-Go SQLite, no cgo). The primitive layer is Base UI (shadcn's default for new projects since mid-2026); Radix remains available via `shadcn init -b radix` if Base UI disappoints. Mantine and MUI were rejected: no source ownership and a default look we'd fight against the established custom dark theme. Components are added incrementally as the UI demands them — not the whole catalog up front.
